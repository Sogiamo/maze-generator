# Maze Generator
---
This is an app that generates simple mazes, in order to learn pyside6 library.

## Getting Started for editors
---
1. Run `git clone https://github.com/Sogiamo/maze-generator.git`.
2. Go into newly created folder using `cd maze-generator`.
3. Run `git remote -v` to check the connection to the repository.
4. Set up your virtual environment and run `pip install -r requirements.txt`
5. You're done!

## Getting Started for app users
---
1. Download [`MazeGenerator.exe`](https://github.com/Sogiamo/maze-generator/releases/tag/v1.0) from github.
